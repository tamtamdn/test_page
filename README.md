# ANBZXY — Landing page

Landing page giới thiệu sản phẩm làm đẹp da thương hiệu ANBZXY.

## Xem thử

Mở file `index.html` bằng trình duyệt, hoặc chạy một server tĩnh trong thư mục này:

```bash
python3 -m http.server 8000
```

Rồi mở http://localhost:8000

## Nội dung mẫu — cần cập nhật trước khi công bố

- Tên sản phẩm, giá, công dụng, thành phần: hiện là nội dung mẫu.
- Đánh giá / hiệu quả: chưa có dữ liệu thật.
- Form liên hệ hiện chỉ hiển thị thông báo trên trang, chưa gửi đi đâu. Cần nối vào email / Zalo / hệ thống bán hàng thật.
- Ảnh hero: ảnh minh họa được tạo bằng AI, không phải ảnh sản phẩm thật.

## Cấu trúc

- `index.html` — toàn bộ landing page (CSS + JS inline)
- `media-generation-anbzxy-hero-0-cafe7530-2ce7-43bf-a5aa-c7085f682592.webp` — ảnh hero minh họa

Repo GitHub dự kiến: `tamtamdn/anbzxy-landing` (public). Đẩy 2 file trên lên nhánh `main` là có thể bật GitHub Pages từ nhánh này.
